# Contributing

Thanks for helping make this starter easier to learn.

## What helps

- Clearer setup instructions and comments.
- Small fixes with a simple explanation.
- Improvements that keep the starter approachable for beginners.

For a larger change, open an issue first so we can discuss it. Keep each pull request focused on one change.

## Before opening a pull request

1. Follow the setup steps in the README.
2. Check that the server starts and `GET /` returns the welcome message.
3. Try the route you changed in Postman or your terminal.
4. Update the README if the behavior or file structure changes.

Describe what changed and how you checked it. Please keep `.env`, passwords, database credentials, and `node_modules` out of your commits.

The auth actions are intentional placeholders. Changes that implement them should explain the behavior and include checks for invalid input as well as successful requests.
